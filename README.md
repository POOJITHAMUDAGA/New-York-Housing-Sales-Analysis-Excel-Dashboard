# NY House Price Dashboard

## Project Overview

Developed an interactive Excel dashboard to analyze New York housing data and present key housing insights through charts, KPIs, and interactive slicers.

## Objectives

* Analyze housing data to identify useful patterns and trends.
* Summarize important metrics using Excel functions and PivotTables.
* Present data in a clear, interactive dashboard.

## Tools and Technologies

* Microsoft Excel.
* PivotTables and Pivot-Charts.
* Excel slicers.
* Data summarization & visualization. 

## Key Features

* Interactive dashboard with charts and slicers.
* Data analysis using PivotTables.
* Visual representation of housing data.
* Interactive filtering for exploring different data segments.

## Files Included

* `NY-House-Dashboard.xlsx` — Excel dashboard.
* `dashboard-preview.png` — Dashboard screenshot.

## How to Use

1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Enable editing if prompted.
4. Use the slicers to filter the dashboard and explore the data.

## Project Outcome

Created an interactive Excel dashboard that organizes housing data into visual summaries to support easier data exploration and interpretation.
